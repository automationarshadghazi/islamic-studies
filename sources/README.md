## Binary files

No original source PDFs are stored in this repository or ZIP. Direct download from the source domains was blocked in the sandbox, although the reading tool could return extracted text. `local_original: false` records the build-time state, not a future download attempt.

Run `python scripts/download_sources.py` from the repository root on an unrestricted network. Downloaded originals are gitignored. Its separate `download_report.json` records per-file status, byte count and hash; failed or HTML-only responses are not saved as PDFs. The script does not magically establish completeness beyond the indexed resources.

## Reuse

The authored audit and notes are independent study aids. Cambridge retains rights in original question papers, mark schemes and reports. Source links direct users to their existing hosts; no official endorsement is implied. Use papers according to the source's permissions. Bibliographic links for case-study background are adjacent to the relevant passages in the notes.
